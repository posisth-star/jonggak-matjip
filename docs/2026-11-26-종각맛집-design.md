# 종각역 도보 15분 맛집 찾기 — 설계 (v2, 카카오)

## 목적
팀 동료들이 점심에 갈 **괜찮은 맛집을 찾는** 웹페이지. 음식 종류별로 주변 식당을 훑어보고, 리뷰는 네이버·카카오에서 바로 확인한다.

## 목표
- 종각역 기준 반경 1.2km(도보 약 15분) 안의 식당을 음식 종류별로 보여준다.
- 식당마다 **네이버 지도에서 보기**, **카카오맵에서 보기** 링크를 단다.
- 링크 하나로 팀 동료들이 같이 본다.
- **무료, 카드 등록 없음.**

## 하지 않는 것
- 평점·리뷰 수 표시와 평점순 정렬 (무료로 쓸 수 있는 API가 없음)
- 네이버·카카오 화면 스크래핑 (약관상 자동 수집 금지, 법적 위험, 잘 깨짐)
- 랜덤 뽑기, 팀 추천·투표 (이번 범위 밖, 써 보고 필요하면 추가)

## 실패로 보는 경우
- 유료 전환이나 카드 등록이 필요해지는 것
- 링크를 눌렀을 때 엉뚱한 식당이 나오는 것

## 제약
- 카카오 로컬 API: 평점·리뷰 필드 없음. 한 번 검색에 최대 45곳(15개 × 3페이지).
- 무료 쿼터: 장소 검색 하루 10만 건(첫 번째 앱만). 넘으면 카드 등록 필요 → 팀 사용량으로는 넘을 일 없음.
- 카카오 장소 정보는 저장하지 않고 열 때마다 받는다(카카오 이용정책상 저장 제한).
- 네이버 지역 검색 API는 한 번에 5곳만 줘서 목록용으로 쓰지 않음.

## 방식 비교
| 방식 | 장점 | 단점 |
|---|---|---|
| **카카오 목록 + 네이버·카카오 링크 (선택)** | 무료·카드 없음, 약관 문제 없음, 리뷰는 네이버에서 확인 | 페이지에서 평점순 정렬 불가 |
| 구글 Places | 평점·리뷰 수 정렬 가능 | 카드 등록 필요, 한국 데이터 적음 |
| 네이버 스크래핑 | 정보 가장 많음 | 약관 위반, 법적 위험, 잘 깨짐 |

## 사용자가 정한 것
- 목적: 맛집 찾기(빨리 정하기 아님)
- 화면: 음식 종류별 목록
- 공유: 팀이 링크로 같이 봄
- 데이터: 카카오 API, 카드 없이 무료
- 리뷰: 네이버 지도 링크로 확인

## 제가 정한 것 (수정 가능)
- 중심점 종각역, 반경 1,200m
- 종류: 한식, 중식, 일식, 양식, 분식, 아시아음식, 카페
- 종류마다 카카오 키워드 검색(음식점 그룹 FD6, 카페는 CE7)으로 최대 45곳
- 정렬: 기본 가까운 순, 이름순 선택 가능
- 식당 카드: 이름, 세부 종류(예: 국수), 도보 N분, 전화번호, 네이버 지도 링크, 카카오맵 링크
- 기술: HTML + 바닐라 JavaScript + 카카오맵 JavaScript SDK(services), GitHub Pages
- 키 보호: 카카오 JavaScript 키에 배포 도메인만 등록

## 구현자에게 남긴 것
- 카카오 세부 종류 문자열(category_name) 실제 형태 확인 후 종류 매칭 규칙 확정
- 네이버 지도 검색 링크 형식 확인
- 결과가 45곳보다 많을 때 어떤 곳이 빠지는지(가까운 순 45곳으로 둠)
